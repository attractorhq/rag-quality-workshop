# Contributing

Keep the core workshop offline, credential-free, synthetic, and focused on
transferable production invariants. Open an issue before changing a stable
interface or the exercise sequence.

Run `npm test` and `npm run typecheck`. Add success, boundary, and failure tests
with behavior changes, and state the learning outcome for new exercises.

Follow the [Code of Conduct](CODE_OF_CONDUCT.md). Contributions are accepted
under Apache-2.0.
